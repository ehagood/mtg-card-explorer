ManaBox Collection Updater

Prepare your collection file for MTG Card Explorer.

1. Export your collection from ManaBox

  1. In ManaBox, open Collection.
  2. Choose Export and select CSV.
  3. Save the CSV to your iPhone's Files app.

2. Choose your CSV file

Choose a ManaBox CSV to begin. Your collection is processed locally in this browser.

Download my-collection.json

🔒 Privacy: The CSV is read and converted entirely on your device. Nothing is uploaded or sent to a server. The tool only creates the JSON file for you to upload to GitHub.

3. Replace the collection file on GitHub

  1. Download my-collection.json above.
  2. Open your GitHub repository in Safari and go to data/my-collection.json.
  3. Use the file's edit menu (pencil) or upload workflow to replace it with the new JSON. Commit the change.
  4. Refresh MTG Card Explorer. You do not need to rerun the Scryfall catalog workflow.

The generated file uses the same version-2 structure as your existing collection file and matches individual printings by Scryfall ID. Copies of the same printing are combined into one entry with the correct quantity.
