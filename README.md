# MTG Card Explorer — V14 (Scryfall Only)

V14 makes Scryfall the sole card catalog and removes the legacy Goblin-catalog workflow from the website UI. It preserves the V12 mobile card-detail behavior and the V13 Artist filter.

## Features
- Searches the Scryfall catalog by card name, artist, rules text, flavor text, type, set, color, rarity, and collector number.
- Filters by set, color, and artist.
- Sorts by card name or set.
- Opens card details with image, rules text, flavor text, printing information, and artist.
- Keeps previous/next card navigation, keyboard arrows, and mobile Image/Details mode.
- Loads the compressed Scryfall catalog generated by the GitHub Actions updater.

## Update an existing site
1. Replace `index.html`, `app.js`, `styles.css`, and `scripts/update_scryfall_catalog.py` with the versions in this ZIP.
2. Keep your existing `.github/workflows/update-scryfall-catalog.yml` if it is already working.
3. Delete `data/goblin-cards.json` from your repository if you want to remove the unused catalog file. The site no longer requests or uses it.
4. Commit and push the changes.
5. Run the **Update Scryfall Catalog** GitHub Actions workflow once. This regenerates the Scryfall data shards with artist names included.

The app cache-busts each data shard using the catalog update timestamp, preventing an old cached shard without artist fields from being reused. The status line reports how many distinct artists were loaded. If it reports zero artists, rerun the workflow after replacing the updater script.

The updater creates/updates `data/scryfall/manifest.json` and the compressed shard files. The first catalog load can take a little time because the app loads the Scryfall data for broad text search. Use a current Chrome, Edge, Firefox, or Safari browser.

## Files
- `index.html` — page structure and filters.
- `app.js` — catalog loading, search, filters, and card details.
- `styles.css` — responsive layout and mobile card-detail styling.
- `scripts/update_scryfall_catalog.py` — builds the Scryfall catalog shards.
- `.github/workflows/update-scryfall-catalog.yml` — example updater workflow; preserve your existing working workflow if it has newer settings.
